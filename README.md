# ☀️ Surya Eco Green Energy – Solar Business Website & Lead Management System

## Project Overview

Surya Eco Green Energy is a full-stack solar energy business website developed using HTML, CSS, JavaScript, PHP, and MySQL. The project is designed to help solar installation companies showcase their services, generate customer leads, calculate solar savings, and manage enquiries efficiently.

The website provides an interactive and user-friendly experience where customers can explore solar products, calculate expected savings, contact the company, and submit enquiry forms. All enquiry data is securely stored in a MySQL database through PHP backend integration.
